# Analysis pipeline for "Computational lineage tracing across ferret and human pancreas reveals conserved acinar and ductal differentiation patterns"

This repository contains the full analysis pipeline and associated scripts for the preprint: [TODO]

## Overview

This study utilizes a single-cell RNA sequencing dataset of the ferret (_Mustela furo_) and a single-nucleus RNA sequencing dataset of the human to investigate the validity of the ferret species as a model for early pancreatic development, specifically in the ductal and acinar pancreatic cell types. The goal of this analysis is to gather pancreatic cell types from the human dataset and apply them to the ferret scRNA-seq dataset, then create pseudotime lineages in both species and compare the gene regulatory programs through early differentiation. This is made possible through the `Seurat` integration toolkit, the `slingshot` and `fitGAM` R packages, and the `CellRank` python package to explore a wide variety of computational lineages through captured timepoints.

Please contact [christopher.2.hill\@cuanschutz.edu](mailto:christopher.2.hill@cuanschutz.edu) with any questions.

## What This Repository Does

This repository provides a complete pipeline for the ferret-human scRNA-seq/snRNA-seq integration and computational lineage tracing. Specifically, it:

-   Visualizes the ferret scRNA-seq and human snRNA-seq datasets in UMAP space and validates the human cell type naming scheme
-   Performs `Seurat` CCA Integration between the two datasets using PCA embeddings and renames the ferret cells according to a k-Nearest Neighbors (k=10) strategy
-   Analyzes the cell type renaming strategy and unbiasedly extracts marker genes from the two species to valiate the integration
-   Recreates PCA embeddings for the original human snRNA-seq dataset using the author's published steps
-   Creates a series of computational pseudotime lineages starting from a progenitor population and moving through ductal or acinar progenitor, immature, and maturing cell types
-   Maps the ferret genes to the human gene list using a curated ortholog file and subsets the two experiments to only use common genes
-   Runs `fitGAM` on the computational lineages to determine the genes most associated with the two ductal/acinar lineages for the two species
-   Calculates terminal lineage fates using `CellRank` and correlation scores of the most associates gene lists and compares them between the species
-   Generates KEGG pathways highlighting ductal or acinar specific differentiation pathways that are shared between the species
-   Creates all plots featured in the manuscript

## Repository Structure

### `csv_files`

The final `.csv` data files that are generated through this analysis pipeline, which include scaled and raw gene correlation scores created by `CellRank`, marker genes by population of either `day` or `final_renamed_celltype` for the ferret dataset that are found through the `Seurat` `FindAllMarkers` function, background genes that are used in the KEGG analysis, or Z-scored gene expression data for the ferret and human datasets which resulted from the cell type validation investigation.

### `docker`

The files required to generate the final Docker container which is found at [TODO: link]. Included in this repostitory is the `R_dependencies.R` file that contains all of the libraries in R v4.4.2 that are required to run this pipeline, the `environment.yaml` configuration file for the anaconda instance and python v3.12.3 packages, the `renv.lock` file that has captures the snapshot of the library when this pipeline was built, and the `Dockerfile` that specifies how this image should be created. Note that this image was created on an arm64 machine using bioconductor docker release 3.20.

### `figures`

All of the figures generated from this analysis pipeline and included in the final manuscript are housed in this location. The prefixed number for each figure corresponds to the scripts in `src` that was used to create the plot.

### `fitgam_objects`

The `rda` files that were generated from running the fitGAM function on the saved `SingleCellExperiment` and `Seurat` object files for each species in the two lineages, specifying the cell type, and start and end cluster that were run with `slingshot` in the downstream `09_ferret_lineages.Rmd` and `10_human_lineages.Rmd`. These `SingleCellExperiment` and `Seurat` object files are not saved here to conserve space, but both can be easily regenerated by running the `07_save_for_fitGAM.R` script. 

### `pseudotime_objects`

The `csv` files containing lineage weights and pseudotime values that were generated using the same `Seurat` objects as well as the start and end clusters for the `fitGAM` calculations. These values were extracted from the calculated `slingshot` computational lineages, and saved along with the `Seurat` objects converted to `.h5ad` file format to move the analysis from R into an python environment. This was necessary as the downstream `CellRank` package does not have a dedicated R implementation, so everything needed to be ported over into a different IDE. The `h5Seurat` and `h5ad` files that were needed for the downsteam `12_cellrank_terminal_fates.py` and `13_correlation_scoring.py` scripts were not uploaded here to conserve space, but both can be easily regenerated by running the `11_save_for_cellrank.R` script.

### `src`

The directory in which all of the source scripts that were utilized in this analysis are located. Most files contain `_helpers.R` files that include a series of helper functions specific to that step, and there is also a `common_setup.R` function that is run prior to all of the R scripts to load in files, directories, and color palettes.

Please find the `README.md` file within the `src` directory for more details on each of these files.

## Outputs

### `figures`

Output: A series of UMAPs, barplots, heatmaps, psuedotime computational lineage trajectories, CellRank terminal cell fate visualizations, and KEGG pathways detailing the integration, cell type validation, lineage drawing, and downstream validation of each of the steps in the pipeline.

### `rds_objects`

Output: All of the `Seurat` objects required to run each step in the sequence in `src`. Note that any of these scripts can be run in any preferred order, or all scripts can be run one after another to regenerate plots and downstream `Seurat` objects.

## How to Run

Each script in the `src` directory can be run by simple language specific execution, either by `Rscript <##_analysis_step>.R` or `python3 <##_analysis_step>.py`.

Depending on your platform, you can execute this directory with the docker image or convert the tarball into a singularity image and execute it on an HPC, either through:
-   `docker exec -it Rscript <##_analysis_step>.R` or
-   `singularity exec ferret_integration_project.sif Rscript <##_analysis_step>.R`

They can be run using the Seurat `.rds` files from [TODO: link], and can be executed in order, out of order, or independently since all intermediate Seurat objects exist in this workspace.

Two external files are required:
-   The human comparison `All cells` snRNA-seq dataset from [Migliorini et al. 2024](https://pubmed.ncbi.nlm.nih.gov/39406230/): [All cells dataset](https://cells.ucsc.edu/?ds=human-fetal-panc)
-   The species mapping file to map ferret gene names to human orthologs from [Yuan et al.](https://www.nature.com/articles/s41586-023-06549-9): [Supplementary Table 10](https://static-content.springer.com/esm/art%3A10.1038%2Fs41586-023-06549-9/MediaObjects/41586_2023_6549_MOESM14_ESM.xlsx)
